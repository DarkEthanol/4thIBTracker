Legal & data use

Privacy policy

Effective 3 October 2026

In brief: 4thIB Tracker uses Google Sheets data only to provide its visible administrative features. OAuth tokens and app data remain on the user’s computer. Ethanol Gaming does not receive, sell or advertise against Google user data.

1. Who operates 4thIB Tracker

4thIB Tracker is an open-source Windows desktop application maintained by Ethanol Gaming. It is intended for authorised administrators of an organised gaming community. Questions about this policy can be raised through the project’s public support and issue tracker.

2. Google user data the app accesses

When a user chooses to connect Google, the app requests the Google Sheets scope shown below:

https://www.googleapis.com/auth/spreadsheets

Google describes this scope as permission to see, edit, create and delete Google Sheets spreadsheets. 4thIB Tracker uses the scope more narrowly: it reads values from spreadsheets that the user has explicitly configured in the app and writes changes needed by its editable spreadsheet features. It does not intentionally create or delete spreadsheets, inspect unrelated spreadsheets, access Gmail, access contacts, or request general Google Drive file access.

Spreadsheet content may include attendance, training, qualifications, logistics, administrative notes and personnel names supplied by the organisation that controls each spreadsheet.

3. How Google user data is used

The app uses spreadsheet data only to provide user-facing functions visible in the desktop application, including:

  • displaying configured administrative records;
  • calculating summaries and highlighting missing or inconsistent records;
  • preparing reports from those records; and
  • writing user-reviewed changes to configured spreadsheets when an editable feature is saved.

Google user data is not used for advertising, credit decisions, surveillance, AI or machine-learning model training, or any unrelated purpose.

4. Storage and retention

On the user’s computer

Google access and refresh tokens are stored by the Google OAuth library inside the current Windows user’s %APPDATA%\4thIBTracker directory. Application settings, user-created tasks, selected report history and embedded-browser session data may also be stored locally. They remain until the user signs out, removes them, or deletes the application data.

In memory

Spreadsheet values are processed in memory while the app is running so that they can be displayed and compared. 4thIB Tracker does not operate a developer-controlled backend that stores copies of Google Sheets content.

In Google Sheets

Spreadsheet data remains in Google’s systems and is retained according to the policies of the spreadsheet owner and the relevant Google account or Workspace organisation.

5. Sharing and transfers

4thIB Tracker communicates directly between the user’s computer and Google’s APIs. Ethanol Gaming does not receive Google access tokens or spreadsheet content through a central application server. Google user data is not sold, rented, disclosed to advertisers, or transferred to data brokers. Data may be disclosed only where the user directs an operation, where required by law, or as necessary for Google to provide its API and spreadsheet services.

6. Google API Limited Use

4thIB Tracker’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Access is limited to delivering and improving prominent user-facing features of the app.

7. Security

Google authorisation takes place in the user’s normal browser. The app uses Google’s OAuth client libraries and HTTPS APIs. Tokens are kept within the user’s Windows profile and are not packaged with application releases. No method of storage or transmission is completely risk-free, so users should protect their Windows and Google accounts and revoke access if a device is lost or compromised.

8. User choices and deletion

Users can disconnect Google from Settings → Google Access → Sign out, revoke access from their Google Account, or remove locally stored app data. Full instructions are available on the data management and removal page.

9. Changes to this policy

This policy will be updated if the app’s Google data use changes. The effective date at the top of this page identifies the current version. Material changes will be reflected in the application and its public source repository before expanded data use is introduced.

10. Contact

Privacy or data-use questions can be submitted through GitHub Issues. Do not include spreadsheet contents, OAuth tokens or other private information in a public issue.
