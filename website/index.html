Unit administration without the spreadsheet shuffle.

Purpose

Built for the weekly admin rhythm

The tracker presents information from user-configured workbooks and community pages in one desktop interface. It helps authorised users review records, prepare reports and apply deliberate updates without replacing the original data sources.

01

Review

See attendance, personnel, course and logistics information in consistent, task-focused views.

02

Reconcile

Compare configured records and surface missing, outstanding or mismatched information.

03

Update

Apply supported spreadsheet changes only through visible user actions, including an explicit save step.

Google Sheets access

Consent first. Local by design.

The tracker connects to Google only after a user selects Connect Google and approves access in their normal browser. The authorisation token is stored in that user’s Windows profile, not on an Ethanol Gaming server.

Why the permission is requested

4thIB Tracker reads cell ranges from existing, user-configured spreadsheets to display administrative records. Where a feature is editable, it writes the user-reviewed changes back to those configured spreadsheets.

https://www.googleapis.com/auth/spreadsheets

What the app does not do

It does not sell Google user data, use it for advertising, train AI models with it, or copy spreadsheet content to the developer’s servers.

Read the full privacy policy

Control

The user stays in charge

Access can be disconnected inside the app at any time. Users can also revoke the grant through their Google Account and remove all locally stored application data from their Windows profile.
